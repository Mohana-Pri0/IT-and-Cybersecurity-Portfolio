## Overview

This personal home lab was completed using **Splunk Cloud Platform** to develop practical understanding of **security monitoring, log ingestion, event analysis, data visualisation and Security Information and Event Management (SIEM) concepts**.

The lab focused on ingesting security-related log data, performing event searches, investigating authentication activity, monitoring VPN connections and visualising security events through a Splunk dashboard.
